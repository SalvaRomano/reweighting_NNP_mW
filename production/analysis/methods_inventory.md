Replicated N=512/1024/2048 snapshots are therefore **not replicated again** during rerun (`results/corrected_mw_rerun/README.md`; rerun input files).
- Matching is a validated one-to-one join by `(model, N, run, step)`, not row position (`scripts/add_cross_poteng_to_thermo.py`). After pooling, original run identity is preserved as `source_run` (`scripts/merge_nnp_runs.py`).
- Current definitions are explicitly reconstructed as `delta_U = cross_poteng - poteng`: `poteng` is the source-Hamiltonian total potential energy, `cross_poteng` is target-Hamiltonian total potential energy for the same configuration, and `delta_U = U_target - U_source` (`scripts/add_cross_poteng_to_thermo.py`; `scripts/compute_energy_averages_and_reweighting.py`). All are eV in `analysis/thermo_all_with_cross_merged.csv`; `delta_u=delta_U/N` is separately stored.

## 8. Reweighting analysis

- Current implementation: `scripts/compute_energy_averages_and_reweighting.py`, input `analysis/thermo_all_with_cross_merged.csv`, output `analysis/energy_averages_and_reweighting.csv`.
- `k_B = 8.617333262145e-5 eV K^-1`, `T=300 K`, and `beta=1/(k_B T)` (`scripts/compute_energy_averages_and_reweighting.py`). The nominal temperature is used, not instantaneous temperatures (`results/cumulant_expansion/README.md`).
- `log(w_i)=-beta*Delta U_i`, with **total** `Delta U_i=cross_poteng-poteng` in the exponent; it is never divided by N. Only the target observable is per-particle, `cross_poteng/N` (`scripts/compute_energy_averages_and_reweighting.py`).
- Stabilization and normalization: `w_i=exp(logw_i-max(logw))`; `p_i=w_i/sum_j(w_j)` (`scripts/compute_energy_averages_and_reweighting.py`). The energy estimator is `sum_i w_i (U_target,i/N)/sum_i w_i` (same path).
- ESS is `(sum w)^2/sum(w^2)`, algebraically `1/sum(p_i^2)`; relative ESS is `ESS/n_frames` (`scripts/compute_energy_averages_and_reweighting.py`).
- First/last saved steps are removed independently per `(model,N,source_run)`, exactly two per trajectory (`scripts/compute_energy_averages_and_reweighting.py`).

## 9. Bootstrap bias analysis

- Current code: `scripts/analyze_ratio_bias.py` and `src/ratio_bias.py`; the theory, bootstrap, and asymptotic fits have been evaluated for physical N=`64,128,256,512,1024,2048` (`analysis/bias_N<N>.csv`, `analysis/bias_N<N>_summary.csv`, and `analysis/bias_N<N>_fits.csv`). Combined tables are `analysis/bias_all_sizes.csv`, `analysis/bias_all_sizes_summary.csv`, and `analysis/bias_all_sizes_fits.csv` (`scripts/collect_bias_all_sizes.py`). Both directions, NNP -> mW and mW -> NNP, are analyzed (`scripts/analyze_ratio_bias.py`).
- Sample sizes: NNP -> mW uses `n={50,100,200,500,1000,1500,2000,5000,10000,20000}`; mW -> NNP uses `n={50,100,200,500,1000,1500}` (`scripts/analyze_ratio_bias.py`). Each uses `100,000` bootstrap replicates and seed `20260923`; direction-specific RNGs are spawned with `SeedSequence` (`scripts/analyze_ratio_bias.py`).
- Sampling is ordinary iid sampling with replacement from the endpoint-trimmed source frames; each replicate draws `n` integer indices (`src/ratio_bias.py`).
- Define `G=U_target/N=cross_poteng/N`, fixed-shift `Y=w=exp(logw-max(logw))`, `X=G*w`, and `theta_full=mean(X)/mean(Y)` on all retained source frames (`scripts/analyze_ratio_bias.py`; `src/ratio_bias.py`).
- Population moments use `ddof=0` via explicit means. `B_theory = mu_X Var(Y)/mu_Y^3 - Cov(X,Y)/mu_Y^2`, and predicted bias is `B_theory/n` (`src/ratio_bias.py`). Empirical bias is the mean of bootstrap ratio estimates minus `theta_full`; bootstrap standard deviation uses `ddof=1`, and `SEM=std/sqrt(100000)` (`scripts/analyze_ratio_bias.py`).
- `B_empirical` is a zero-intercept weighted least-squares fit of bias against `1/n`, with inverse-variance weights `1/SEM^2`; its SEM is `sqrt(1/information)` (`src/ratio_bias.py`). Fits are reported for `n_min={50,100,200,500}` (`analysis/bias_N64_fits.csv`; `analysis/bias_N512_fits.csv`). The command documented as current uses primary `n_min=50` (`README.md`).

## 10. Cumulant analysis

- Current code/output: `scripts/analyze_cumulant_expansion.py`, `src/cumulant_expansion.py`, and `results/cumulant_expansion/summary.csv`.
- `V=-beta*(cross_poteng-poteng)` uses total eV; `G=A=U_target/N=cross_poteng/N` in eV/particle (`src/cumulant_expansion.py`). Maximum order is four (`scripts/analyze_cumulant_expansion.py`).
- With `dV=V-mean(V)` and `dG=G-mean(G)`: `C0=mean(G)`; `C1=mean(dV*dG)`; `C2=mean(dV^2*dG)/2`; `C3=[mean(dV^3*dG)-3 mean(dV^2)mean(dV*dG)]/6`; `C4=[mean(dV^4*dG)-6 mean(dV^2)mean(dV^2*dG)-4 mean(dV^3)mean(dV*dG)]/24` (`src/cumulant_expansion.py`; `results/cumulant_expansion/README.md`).
- The order-m partial sum is `sum(C0,...,Cm)`. Truncation is assessed against the full stably shifted exponential weighted mean `sum(G exp(V-max(V)))/sum(exp(V-max(V)))`; errors versus the direct target mean are also stored (`src/cumulant_expansion.py`; `scripts/analyze_cumulant_expansion.py`).
- Validation differentiates an eighth-degree local interpolant to the tilted mean on a symmetric lambda grid; all 12 size/direction groups are checked through fourth derivative, with maximum absolute discrepancy `4.3e-9` (`results/cumulant_expansion/README.md`; `results/cumulant_expansion/derivative_verification.csv`). Unit tests independently cover an asymmetric synthetic sample and total-energy use in V (`tests/test_cumulant_expansion.py`).

## 11. Structural analysis

- Current implementation: `scripts/compute_rdf_N256.py` (historical name but supports N=`64,128,256,512,1024,2048`), with reusable pair counting in `src/rdf.py`; all-size outputs are `analysis/rdf_N256.csv` and `results/rdf_all_sizes/rdf_N<N>.csv`.
- Bins use `dr=0.02 Å`; `r_max` is half the shortest box length, with the terminal bin adjusted to end exactly there (`scripts/compute_rdf_N256.py`; `src/rdf.py`).
- Coordinates are wrapped into the orthorhombic periodic box and queried with SciPy `cKDTree(...,boxsize=lengths)`, giving minimum-image periodic pairs. Self pairs are removed and distinct pairs divided by two (`src/rdf.py`).
- Each frame is independently normalized as `histogram/[0.5*N*(N/V)*shell_volume]`; frame RDFs are then directly averaged or combined with frame probabilities. An already averaged RDF is never reweighted (`src/rdf.py`; `scripts/compute_rdf_N256.py`; `README.md`).
- Weights are matched to frames by `(model,source_run,step)` after endpoint removal. They use total Delta U and a single normalization across all retained frames for a model/size (`scripts/compute_rdf_N256.py`).
- First peak: first peak from `scipy.signal.find_peaks` with prominence `0.05` and minimum separation `8` bins. First minimum: first peak in `-g` after that peak, prominence `0.03`, separation `8` bins (`src/rdf_features.py`).
- Coordination is the shell-volume integral `rho * integral 4*pi*r^2*g(r)dr`, treating RDF values as bin averages and fractionally integrating the cutoff-containing shell (`src/rdf_features.py`). For published comparisons all four curves and all six sizes use one `r_c=3.50 Å`, the rounded mean (`3.503 Å`) of direct-mW minima spanning `3.49--3.53 Å` (`src/rdf_features.py`; `results/rdf_all_sizes/coordination_summary.csv`).
